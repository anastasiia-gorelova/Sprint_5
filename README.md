# Sprint_5

Учебный проект UI-автотестов сервиса «Доска» (https://qa-desk.education-services.ru/).
Тесты написаны на Python с использованием Selenium и pytest и настроены на Google Chrome.

## Проверяемые сценарии

В проекте семь тестов:

- Успешная регистрация нового пользователя.
- Ошибка регистрации с некорректным email: сообщение «Ошибка» и красное оформление трёх полей.
- Ошибка регистрации уже существующего пользователя.
- Вход пользователя: отображение аватара и имени.
- Выход пользователя: исчезновение аватара и имени, появление кнопки «Вход и регистрация».
- Попытка создать объявление без авторизации: показ модального окна.
- Создание объявления авторизованным пользователем и проверка его названия в блоке «Мои объявления».

## Структура проекта

- `tests/test_registration.py` — три сценария регистрации.
- `tests/test_authorization.py` — вход и выход пользователя.
- `tests/test_advertisements.py` — два сценария создания объявлений.
- `conftest.py` — общая фикстура `driver`: отдельный Chrome для каждого теста, закрытие через `quit()` после выполнения.
- `locators.py` — именованные локаторы с методами поиска Selenium.
- `data.py` — статические данные пользователя и объявления, ожидаемые тексты и значения.
- `helpers.py` — генераторы email, паролей и названий объявлений.
- `url.py` — адрес учебного сервиса.
- `requirements.txt` — зафиксированные версии Selenium и pytest.
- `pytest.ini` — поиск тестов в `tests` и добавление корня проекта в путь иморта.
- `.gitignore` — исключения для виртуального окружения, кешей и локальных файлов.
